# sjsu-data226-FA26

This course provides hands-on experience in designing and building modern data platforms, covering big data processing, data warehousing, and end-to-end data pipelines. Students learn to work with industry-standard tools and technologies such as Apache Spark, Kafka, Snowflake, Airflow, and dbt. Through practical labs and team projects, students develop skills in batch and real-time data processing, data modeling, pipeline orchestration, and scalable data engineering, preparing them to build production-ready data systems.
